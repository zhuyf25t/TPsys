# GameScene Final Cleanup Tickets V3

## 1. Purpose

This document lists only the tickets that are still truly necessary to satisfy the **hard-gate** completion standard for `GameScene.ts`.

These are not broad new phases. They are the last targeted cleanup tickets required to remove the remaining non-host residue that still exists in the scene.

---

## 2. Ticket Selection Principle

A V3 cleanup ticket is included only if it removes one of these remaining classes:

- presentation / dictionary helpers that should not remain in scene
- runtime-local geometry helpers that should not remain in scene
- legacy / dead scene residue that still pollutes the host layer

If a ticket does not directly help satisfy the hard-gate standard, it is not listed.

## 5. Not Worth Adding As Tickets

These are intentionally **not** new V3 tickets:

- camera micro-cleanup
- additional VFX micro-splitting
- HUD bridge micro-cleanup
- lifecycle / orchestration micro-cleanup

Reason:

- they do not directly block the hard gate
- they are more likely to produce low-value fragmentation than architectural improvement

---

## 6. Hard-Gate Completion Rule After V3 Tickets

Completion can be declared only if:

1. `GameScene` no longer contains presentation / label / dictionary helpers
2. `GameScene` no longer contains runtime-local geometry helpers
3. `GameScene` no longer contains legacy runtime residue
4. the remaining methods can all be justified as scene host / renderer host / actor glue / HUD bridge / scene-side motion/VFX glue
5. either:
   - the size target is met
   - or the remaining overage can be justified line by line as acceptable host glue

This condition is now satisfied.

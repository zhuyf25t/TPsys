# Slay.one Minimal Menu Rewrite Plan

## Goal

把首页和 `/battle` 从网页门户语法收紧成极简游戏菜单语法。

## Home

首屏只保留：

- 玩家面板
- 当前配置摘要
- 最强开始按钮
- 配装按钮
- 一个次级入口

首屏删除或降级：

- 全量主导航
- 功能矩阵
- 最近战报列表
- 最新讨论列表
- 活动摘要
- 多余说明卡片
- 三个以上 CTA

## Battle

只保留：

- 左上小入口：回放 / 讨论 / 排行
- 右下小入口：站内信 / 社交通知
- 极简状态区
- 极简战后结算

删除或降级：

- 大段说明文字
- 过大的 quick panel
- 过大的状态卡
- 过多战后动作
- 过强网页 modal 感

## Acceptance

- 首页像主菜单，不像门户
- `/battle` 像游戏内壳，不像网页 battle page
- `View all` 只承担正文页跳转
- 真实数据 / 诚实空状态继续保留

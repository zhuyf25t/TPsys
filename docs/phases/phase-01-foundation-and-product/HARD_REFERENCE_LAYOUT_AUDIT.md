# Hard Reference Layout Audit

## 首页当前最该被推翻的点

1. 不能继续把首页做成功能门户。
2. 不能再让开始按钮和一堆模块卡片平级。
3. 不能继续用顶部网页导航定义首页。
4. 不能继续用大段说明文字解释系统。
5. Replay / Forum / Rank / Mail / Social 只能退到角落入口。
6. 主视觉必须围绕中央菜单窗，而不是网页 hero。

## `/battle` 当前最该被推翻的点

1. 不能继续保留顶部状态小框。
2. 不能继续把 battle 做成网页页面里的一个模块。
3. 左上 / 右下入口必须是极小按钮，不是大按钮。
4. quick panel 必须像游戏菜单，不是网页 drawer。
5. 战后结算必须只保留极少动作。
6. active battle 时附属系统入口必须隐藏。

## 这轮重建规则

1. 首页直接改成游戏主菜单。
2. 中央只保留玩家、配置、开始。
3. 配装继续挂在同一个大厅壳里。
4. `/battle` 固定为游戏内框架。
5. 回放 / 论坛 / 排行 / 邮件 / 好友 先 preview，再 `查看全部`。

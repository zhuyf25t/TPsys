# Demo Readiness Report

## 当前真实状态

当前前端已经不是网页门户，而是：

- 首页 = 游戏主菜单
- `/loadout` = 同一大厅里的战前模式
- `/battle` = 游戏内框架
- 角落入口 = 附属系统 preview
- `查看全部` = 文本正文页承接

## 当前主路径

1. 首页进入大厅
2. 调整配装
3. 进入 `/battle`
4. 10 秒匹配
5. 进行 6 人单命战斗
6. 战后结算
7. 从 quick panel 或 `查看全部` 去 replay / mails / rating

## 仍需验证

1. battle 统一试玩与手感微调
2. 大厅与 battle 的材质感是否还要继续往 slay.one 靠
3. 战后结算的仪式感是否还要继续加强
